# Production asset pass

Toolkit-guided production contracts for the latest visual exploration.

- `docs/art-direction.md` is the visual system and export policy.
- `assets/production-manifest.json` tracks 41 planned individual assets with frame states and QA.
- `docs/combat-feedback.json` describes restrained, event-driven impact feedback.
- `docs/screen-flow.json` defines browser UX and screen acceptance flows.

**Important:** The 39 existing concept SVGs in `assets/` are still placeholders. The latest two illustrated sheets are *references*, not a sprite atlas. No image has been inaccurately labeled production-ready or sliced from those contact sheets.
