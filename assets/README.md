# Brickbound foundation asset kit

39 original vector concept assets, editable as SVG. Built for responsive browser rendering.

## Visual rules
- Matte silhouettes, coarse fantasy geometry, sparse detail, restrained edge highlights.
- Palette: ink #182232, navy #253145, parchment #e6d4b1, muted gold #d9b47e, sage #86ac9b, coral #c27a70, violet #9385aa.
- Use a distinctive **licensed** angular serif display font for titles and a highly legible sans for UI; no font files are bundled. SVG wordmark uses system Georgia as a temporary fallback.
- Damage feedback uses movement, scale and shape in addition to colour.

## Layouts and flow assets
- Home: logo, emblem, buttons, world background.
- Combat: world background, brick/enemy/boss layers, elemental balls, health bar, panel.
- Upgrade/shop/hero/pause/victory/defeat: reusable panel, card and buttons.
- Worlds: six background colour themes; separate enemies and bosses.

## Asset status
These are first-pass **vector masters**, not final approved production sprites. Review at 360x640 and 1280x720, test contrast and collision readability, then create sprite atlases, animation frames, and compressed web assets. No external art assets are included.
