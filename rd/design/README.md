# Brickbound · Research & Design
This folder is the reference archive for the **original illustrated Brickbound: Dungeon Volley** concept and 60-stage progression design.

## Design references
- [Main menu concept](mockups/main-menu-concept.webp) — early fantasy UI / game menu concept
- [Screen flow mockups](mockups/screen-flow-mockups.webp) — main screen and interaction flow exploration
- [Screen collection](mockups/screen-collection.webp) — cross-screen visual reference
- [Asset compendium](mockups/asset-compendium.webp) — original character, enemies, materials and UI direction
- [World expansion sheet](mockups/world-expansion-sheet.webp) — additional assets, enemies and environments
- [Product specification](product-spec.pdf) — foundational game design and feature specification
- [Level design source](level-design.json) — authored 60-stage progression data

The mockup images are high-quality **WebP exports at the same pixel dimensions as the original generated PNGs**. They are design references, not sprite atlases or drop-in game assets. All UI words, numbers and decorative frames baked into these images remain non-interactive.

**Source-of-truth:** `/levels.json` is the runtime game data. The copy here preserves the design reference at the time of archival; edit the runtime file for gameplay changes.

The game currently uses some assets extracted from composite sheets, and some crops have visible neighboring art fragments. See [asset quality notes](asset-quality-notes.md) before replacing runtime sprites.
